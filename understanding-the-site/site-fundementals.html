Site Fundementals

Visit the Ownership Passover Steps to see how to transfer ownership of the site.

index.html is one HTML filethat contains everything for the websites frontend. This works in tandem with Supabase, which handles the back end data of the site. Vercel is used to actually host the website, providing the live link accessable to everyone. Please view Site Organization.canvas to see a visual on how all the platforms interact with each other.

External Libraries bring in external functionality for both Supabase functionality and excel tracking exporting functionality

Authentication is handled by Supabase - which includes sign in credential storage, invites, and module and lesson data. It also handles roles and permissions using Edge Functions

Vercel hosts the app itself, which is a single .html file running the full site.

How to push app updates:

When updating the site, the main aspect is adjusting the Github Repo. Click the link to the Github Repo page to learn more.

Use Supabases "SQL Editor" to update, add, or remove tables for the backend data (See Supabase for more info).

AI was heavily used in the creation of this project. Please review the AI Usage page for more details.
